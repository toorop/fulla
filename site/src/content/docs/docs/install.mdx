Fulla runs in **Photoshop 27.11 or later** (Help > About Photoshop shows your version; on macOS, Photoshop > About Photoshop), on Windows and macOS. The simplest way to install it is from Adobe Exchange, Adobe's plugin marketplace.

## From Adobe Exchange (recommended)

1. Open [Fulla on Adobe Exchange](https://exchange.adobe.com/apps/cc/bd8f7dbc) and click **Free**. Sign in with your Adobe ID if asked.
2. The Creative Cloud app opens and installs Fulla.
3. In Photoshop, open **Plugins > Fulla**, then [connect an AI service](/docs/first-run/).

**Already have Fulla from GitHub?** Uninstall it first: in the Creative Cloud app, find Fulla in your list of plugins and click **Uninstall** (or double-click **Uninstall Fulla.bat** if you used the Windows installer), then install it from Adobe Exchange. The two are separate plugins for Photoshop: connect your AI service again in the new one, as keys and settings don't carry over.

## From GitHub (Windows and macOS)

New versions come out here first, before Adobe has reviewed them.

1. Download [fulla.ccx](https://github.com/toorop/fulla/releases/latest/download/fulla.ccx), the latest version.
2. Double-click it. Creative Cloud says the plugin comes from a third-party developer: click **OK**. The first time you install such a plugin, Windows may ask for administrator permission.
3. In Photoshop, open **Plugins > Fulla**.

No administrator rights on this computer? Use the Windows installer below.

## Without the Creative Cloud app or administrator rights (Windows)

1. Download [fulla-windows.zip](https://github.com/toorop/fulla/releases/latest/download/fulla-windows.zip), the latest version, and unzip it.
2. Close Photoshop.
3. Double-click **Install Fulla.bat**. No admin rights are needed.
4. Start Photoshop and open **Plugins > Fulla**.

### What the Windows installer changes

- It copies the plugin to `%APPDATA%\Adobe\UXP\Plugins\External\io.github.toorop.fulla`.
- It adds one entry to Photoshop's plugin list, `%APPDATA%\Adobe\UXP\PluginsInfo\v1\PS.json`, after saving a backup copy next to it. Other plugins are left untouched.
- **Uninstall Fulla.bat** removes both again.
